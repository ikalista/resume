## 项目经历

### 1. 反欺诈系统 - 多模态模块（2025年1月 - 2026年7月）

**背景**：风控核心场景需融合通话声学、进件自拍/人脸识别图像、对话文本三路信号识别中介代办与黑产团伙，原 LightGBM 基线 AUC 仅 0.77；已有文本特征基础，但声学与图像侧缺少可规模化落地的特征链路与识别能力。

**行动**：

- 作为多模态 & NLP 算法组 Tech Leader，推动声学、人像、背景及声学年龄、图片年龄、身份证年龄差异等特征进入融合与告警链路，支撑中介代办与黑产团伙识别的差异化处置；三模态特征汇总后，客诉预测模型 AUC 从 0.77 提升至 0.85，平均每月降低资损约 60 万元。
- 主导通话音频预处理、声纹 embedding 提取及离线分析链路建设，通过流水线并行将日均处理吞吐量从 50 万通提升至 300 万通，累计处理 5000 万通录音，支撑声学特征在风控场景中的规模化落地。
- 针对内部通话数据完成清洗、切分与声纹模型微调，将内部数据集 EER 从 19% 降至 11%；部署 Qwen-Omni 等开源多模态模型，提取静音时长、断崖式沉默等标量特征，用于反欺诈识别与客诉预测。
- 主导进件自拍图像预处理、embedding 提取及离线分析链路建设，累计处理 2000 万张图片；基于背景 embedding 聚类发现批量代申请团伙与异常环境模式，增强图像侧对中介代办与黑产线索的识别能力。
- 引入 QwenVL 处理耳机检测与单据金额校验等视觉审核任务，其中耳机检测经 72B 构建标注流水线、蒸馏至 7B 后微调，业务数据集准确率从 84% 提升至 90%，疑难图片准确率从 57% 提升至 78%，单据金额校验准确率达到 98%。

### 2. 数据智能与建模智能（2025年6月 - 2026年7月）

**背景**：公司智能化转型需要在 NL2SQL、自动化建模评测（MLE-bench）与内部表格建模之间建立可复用的数据与模型链路，并形成稳定评测、训练和落地闭环。

**行动**：

- 围绕团队 Text2SQL 主线，复现并对齐基座评测、数据生成与强化学习训练链路，选定 OmniSQL（Qwen2.5-Coder 7B/14B）作为基座，系统对比 DAPO 与 GRPO 在 7B/14B × LoRA/FULL 四组配置下的训练表现，主线收敛为稳定性更优的 DAPO。
- 引入重试机制、样本筛选和空结果过滤缓解奖励稀疏问题，将 7B 单次解码得分提升至 68.6，14B self-consistency 得分提升至 71.1；团队 BIRD 榜单达到 dev 71.10 / test 73.45，单模型世界第 6（2025.9）。
- 定位 vLLM 高 batch 推理下 KV cache 异常，将 `batch_size` 收敛至 8 的稳定配置；完成 MLE-bench / MLEvolve 复现，基于 MLEvolve + DeepSeek 在 MLE-bench lite 划分上复现 73 分基线，接入公司内部建模流程后，新客风控等场景 AUC 较人工建模提升约 1% - 2.5%。

### 3. 坐席智能系统（2023年9月 - 2026年7月）

**背景**：外呼通话场景下需同时覆盖坐席违规识别与客户意图捕捉两条链路，共 59 个语义点；初期依赖正则规则，准确率仅 60% - 70%，且新增语义点开发周期长、维护成本高。

**行动**：

- 主导通话语义理解系统从 0 到 1 建设，先以正则规则快速上线覆盖高频场景，积累标注数据后引入 BERT 做细粒度语义点分类训练，准确率提升至 80%+。
- 设计 AutoPrompt 数据构造流程解决标注瓶颈：业务提供 100 条标注样本，使用 DeepSeek-R1 迭代优化 prompt，再以最优 prompt 生成式标注 10000 条数据；基于标注数据对 Qwen2.5 做 LoRA 微调，按语义点复杂度部署 7B 与 0.5B 模型，将语义点分类准确率从 60% - 70% 提升至 90%，覆盖 59 个语义点。
- 基于 Qwen2.5-14B 扩展工单填写与通话小结能力，形成“实体抽取→字段映射→结果校验”的自动化链路，工单填写准确率达到 93.5%，实现日均 9 万通通话全量覆盖；沉淀的词频、话术标签、情绪标签等文本特征资产复用至多模态反欺诈系统文本模态。

### 4. 视频生成与 RTA 素材生成验证（2026年）

**背景**：RTA 投放与风控审核场景需要快速生成多版本视频素材，用于覆盖不同人群、话术、画面风格和风险提示表达；传统人工剪辑周期长、变体数量有限，难以支撑高频创意测试与素材审核策略验证。

**行动**：

- 围绕 Wan、SeedDance 等视频生成模型完成素材生成链路验证，拆解文生视频、图生视频、首尾帧约束、镜头运动、人物一致性和字幕口播同步等关键能力，形成适合 RTA 素材生成的 prompt 模板与参数配置规范。
- 设计“脚本生成→分镜拆解→关键帧生成→视频生成→字幕/口播补齐→人工质检”的流程，将投放卖点、合规提示、风险话术和品牌元素拆成可复用素材单元，支持同一脚本下生成多画风、多镜头、多节奏的视频变体。
- 借鉴机器人世界模型中的时序一致性和动作可控性思路，重点评估视频生成结果在人物身份保持、物体交互、场景连续性和动作合理性上的稳定性，并沉淀人工筛选标准，用于过滤闪烁、畸变、语义漂移和合规风险片段。
- 将生成素材用于内部样例评审与 RTA 创意方案验证，产出可复用 prompt、分镜模板和质检 checklist，为后续接入自动化素材生产、A/B 测试和投放效果回收预留链路。
