# AI专项两页大纲

## 第一页：AI专项价值与方法路径

### 1. 项目价值：用AI降低外诉、提升退费处置收益

- **压降外诉**：围绕 12378、资方监管、地方监管等外溢场景，提前识别高风险客户，在建单前、首次触达前、首次触达后等关键节点前置干预；同步用 AI 承接首通回访、标准话术、工单高亮、专项组分流等动作，缓解人工积压导致的并发投诉。
- **退费优化**：基于客户类型和诉求强度，区分协商型、强硬型、法律维权型、小白型、专业型等人群，判断谁可协商压降、谁必须赔付，匹配差异化退费力度，在控制赔付总额的同时提高议价空间。
- **经验沉淀**：把专家经验、优秀坐席处理方式、历史案例持续沉淀为可复用模型能力，用 AI 辅助提效日常处置；同时从纪要、通话记录、工单和处置结果中提炼 Top 问题、Top 话术、Top 案例，反哺 AI 模型并形成管理复盘机制。

### 2. 方法路径：大模型 + 专家经验 + 数据闭环

> 流程图（从左到右）：**电话** → **大模型** → **行为识别** → **客群分类** → **处置策略**

- **① 电话**：采集客户通话文本、12378 拨打记录、工单记录、短信触达记录、退费与投诉结果等多源数据。
- **② 大模型**：将专家经验嵌入大模型，采用自顶向下业务规则归类与自底向上聚类并行，提取客户行为信号；通过多基座交叉验证和人工复核提升准确率。
- **③ 行为识别**：识别投诉倾向、外溢风险、退费诉求强度、沟通方式等行为特征。
- **④ 客群分类**：沿两个维度对客户打标——
  - 专业性维度：小白型（不懂规则、易引导）/ 豆包人（有一定了解、需技巧）/ 专业型（熟悉法规、强维权）
  - 诉求/态度维度：强硬型（态度强硬、威胁外诉）/ 协商型（有余地、可谈）/ 软弱型（易接受、低风险）
  - 等待挖掘
- **⑤ 处置策略**：根据客户类型和诉求强度，输出分流建议、外呼话术、退费力度、拒绝方式、跟进周期；结果反哺模型形成数据闭环，映射到价值上。

## 第二页：任务拆解与资源安排

### 1. 任务拆解：两条洞察链路并行推进

**链路一：基于业务知识的洞察**

> 用大模型承接专家经验，先形成可解释的用户行为洞察，再沉淀为可验证、可下钻的分群分析框架。
> 流程：**大模型 + 专家知识** → **用户行为洞察** → **专家知识分群洞察** → **分群下钻分析**；同时保留 **大模型直接分群洞察** → **分群下钻分析** 的短接路线。

- **大模型 + 专家知识输入**：汇总客诉分类、风险信号、退费经验、坐席话术、历史外诉案例等业务知识，转化为模型可识别的标签定义、判断标准和提示词模板。
- **用户行为洞察**：从通话文本、工单记录、触达记录中抽取客户诉求、情绪强度、沟通方式、威胁外诉、反复进线、退费预期等行为信号，形成客户级行为画像。
- **基于专家知识的分客群洞察**：按照专家预设的专业性、诉求强度、风险等级等维度进行客群切分，明确每类人群的业务含义、判断依据和处置优先级。
- **大模型直接分客群洞察**：让大模型不完全受专家框架约束，直接基于客户表达和行为轨迹给出客群判断，作为专家分群的短接校验路线。
- **分群下钻分析**：将专家分群和大模型直接分群统一回收到分群下钻分析中，对每类客群继续拆解 Top 诉求、典型话术、风险触发点、退费敏感度和推荐处置策略。

**链路二：基于大模型的自动化挖掘**

> 不预设业务结论，通过 embedding 和聚类算法从原始通话中自动发现同质化客群与潜在新维度。
> 流程：**大模型 + embedding + 聚类算法** → **聚类行为洞察** → **同簇通话同质化信息挖掘** → **新客群/新维度反哺**。

- **大模型 + embedding + 聚类算法**：对全量通话文本进行向量化表达，结合聚类算法形成自然分组，初步识别文本语义、情绪表达和诉求模式相近的客户簇。
- **聚类行为洞察**：针对同簇通话，使用词频统计、关键句抽取、大模型总结等工具，提炼该簇的共性诉求、典型表达、情绪特征和外诉倾向。
- **同质化信息挖掘**：对每个聚类簇输出"这群人为什么相似、风险点在哪里、适合什么处置方式"，发现专家分类未覆盖的隐性行为模式。
- **横向比较与发现**：将聚类结果、大模型直接分群、专家知识分群以及其他团队洞察进行对比，识别一致结论与差异结论，例如大模型认为的"豆包人"与专家规则定义下的客群有何不同。
- **规则反哺与维度补充**：把有效的新客群、新诉求、新风险信号反馈到专家框架中，沉淀为新的标签、规则、话术或评测样本。
