# 客户痛点
1. **外部供应商无法满足业务时效要求**：业务方要求1个月完成存量录音的全量裁剪清洗及向量化处理，外部供应商预估需要3-4个月，存在严重的时间缺口，无法满足业务需求。
2. **黑产威胁日益严峻，传统人工分析难以应对**：面对海量录音数据（总量7000万条），传统人工分析无法全量甄别伪造身份、团伙作案等威胁，急需建立智能化声纹反欺诈体系，精准识别黑产，降低运营成本。
3. **数据价值未充分挖掘，缺乏自主可控技术能力**：当前风控体系主要依赖结构化数据，海量录音数据（7000万条）价值还未得到充分挖掘利用；外部供应商存在数据安全、成本控制等风险，急需建立自主可控的声纹反欺诈技术能力。

# 四阶段里程碑规划
能力上限，两张图，技术痛点缩掉，一张架构图

## 阶段一：从无到有 - 基础工程建设（630）
**目标**：建立声纹反欺诈基础技术能力，完成存量数据跑批
- 项目架构：构建流批一体化项目架构，支撑增量/存量声纹识别全链路
- 模型选型：完成ECAPA-TDNN、ERes2Net、CAM++、ReDimNet等SOTA模型选型与部署及水位摸排
- 性能优化：存量录音裁剪与向量提取，将流水线并行的吞吐量从10万/天提升至100万/天，达到要求
- 建立声纹库：630前完成2600万通录音的裁剪与向量提取，建立基础声纹特征库
- **关键指标**：建立稳定的跑批链路，完成100万录音/天处理能力。

## 阶段二：从有到准 - 模型效果优化 （930）
**目标**：提升模型精度，达到业务可用水平，降低推理成本
- 数据增强：速度扰动、噪声增强、混响模拟、随机裁剪等提升模型鲁棒性
- 消融实验：业务数据集+开源数据集扩充，增量/全量训练策略优化
- 超参调优：AAM-Softmax的m值调优，模型结构改进
- 模型选型：部署ReDimNet等最新SOTA模型
- 聚类分析：建立声音模态特征数据挖掘能力，基于声纹向量进行Deep SCAN/KNN聚类分析，识别潜在黑产团伙和异常用户群体
- **关键指标**：EER从20%降低至10%以下，90%准确率下召回率≥30%，在保持开源数据集效果（1%）基础上显著提升业务数据集表现

## 阶段三：从准到全 - 声纹特征中台建设（1230）
**目标**：建立VID体系，构建多模态特征融合的声纹反欺诈中台
- VID体系：建立声纹身份标识（VID）体系，实现跨业务场景的用户声纹统一标识
- 特征融合：引入WavLM+ECAPA等自监督大模型，构建多模型融合架构，结合TDNN、Res2Net、ReDimNet等模型优势
- 多维风控：融合结构化数据（用户画像、行为数据）与声音模态特征，构建多维度风控模型
- 可解释特征：提取用户情绪、显式声音特征等，助力业务分析
- 多模态认证：探索声纹+其他生物特征（人脸、指纹）的多模态身份认证
- **关键指标**：建立千万级VID库及特征库，覆盖借款、客服、电销业务线

# 风险与应对
1. **技术风险**：模型效果不及预期 → 多模型融合+持续数据增强策略
2. **工程风险**：大规模推理稳定性 → 完善监控重试机制+资源调度
3. **时间风险**：里程碑节点紧迫 → 并行+关键路径优化
4. **合规风险**：录音数据安全 → 数据脱敏+访问权限控制


# 技术痛点
1. **工程性能瓶颈**：裁剪及声纹模型运行，需要大量计算资源（8台机器800C 800G+8*A30显卡）进行CPU/GPU混合推理，资源调度非常复杂。
2. **模型效果不足**：当前EER水位20%，距离业务目标10%（声扬）存在较大差距，缺乏针对业务场景的模型优化和数据增强策略。开源数据集上EER普遍是1%，也存在极大的gap。
