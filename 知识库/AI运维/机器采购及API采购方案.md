# 大模型-机器采购及API采购方案

## 1. 结论
首先，从稳定性方面来说，L20是2023年发布的成熟产品且未被禁售，而H20和阿里PPU（尤其）都是近一年发布的新品；其次，显存单价上，L20（0.13万/GB）和PPU（0.117万/GB但需16卡起购）性价比显著优于H20（0.213万/GB）；再者，由于业务急需上线，我们无法承担新卡调试风险，L20驱动生态成熟可立即部署，而PPU强依赖阿里云适配存在不确定性；最后，模型兼容性上，L20无缝支持主流框架，PPU可能存在限制风险。综上，基于成本优势、成熟稳定、快速部署和广泛兼容性，L20是最符合当前紧急业务需求的选择。

## 2. 背景
随着AI技术的快速发展，公司内部对大模型（如DeepSeek）的需求日益高涨。需要高效的计算资源和灵活的API服务来支持的精益运营，开发。作为人工智能团队，其实有必要对这些需求进行收口管理。一方面，通过管控权限，可以更好地判断哪些场景适合使用API接口，哪些场景需要自行部署；另一方面，这也有助于确保数据安全，避免敏感信息泄露或滥用。

本方案旨在为团队理清现状，并提供机器采购和API采购的指导。

### 5.1 需求分析
- **模型类型**: 支持大语言模型（如DeepSeek、GPT等）。
- **调用频率**: 根据团队需求选择合适的调用量套餐。
- **安全性**: 确保数据传输和存储的安全性。

### 5.3 自行部署 vs API采购

| **方案**       | **优点**                                                                 | **缺点**                                                                 |
|----------------|--------------------------------------------------------------------------|--------------------------------------------------------------------------|
| **自行部署**   | - **资源利用率高**：GPU集群统一管理，灵活调度任务（训练/推理/闲时任务）<br>- **数据安全可控**：内部闭环处理<br>- **长期成本低**：高频使用时摊销成本优势显著 | - **初始投入高**：需采购硬件和运维团队<br>- **扩展性受限**：资源固定，扩容需额外采购 |
| **API采购**    | - **零初始成本**：按需付费，无硬件投入<br>- **弹性扩展**：动态调整调用量<br>- **免运维**：由服务商全托管       | - **资源利用率低**：无法统一调度闲时资源<br>- **长期成本高**：高频调用费用飙升<br>- **数据安全问题**：需额外安全保障措施 |

API采购因资源隔离无法实现跨业务调度，容易出现资源闲置或争抢的情况。按量收费一定程度可以避免该问题，最本质的解决方案是需要统一收口进行调度及资源最大化利用。

### 6.2 DeepSeek-R1 回本计算
- **需求**: FP8需要670GB显存，至少需要8卡H200/H20。
- **硬件成本**: 参考PowerEdgeXE9680配置，8卡H200服务器报价为240万。

- 回本所需tokens = ￥240万 / 8 = **30万百万tokens**。
