# 开源评测集一览

图例：🌕 完全包含 / 🌗 部分包含 / 🌑 不涉及

| 评测集 / 框架名称 | 数据获取(取数/SQL) | 数据准备(清洗/特征) | 数据分析(EDA/探索/推理) | 建模与训练(树模型/DL等) | 数据呈现(图表/报告) | 核心定位与业务场景 |
|--------------------------|:------------------:|:-------------------:|:----------------------:|:------------------------:|:-------------------:|---|
| **【一】端到端智能体与全栈工程（End-to-End Agents）** | | | | | | |
| MLE-bench                | 🌗 | 🌕 | 🌕 | 🌕 | 🌑 | 标杆：基于 Kaggle 的全栈 ML 工程闭环，重度考察各种复杂模型的训练与调优。 |
| AutoKaggle               | 🌗 | 🌕 | 🌕 | 🌕 | 🌗 | 多智能体：模拟真实 Kaggle 竞赛，覆盖从 EDA 探索到最终选型建模的过程。 |
| InsightPilot             | 🌗 | 🌕 | 🌕 | 🌑 | 🌕 | 探索系统：专精于发起查询和 EDA，不涉及后端复杂机器学习建模。 |
| DS-Agent                 | 🌑 | 🌗 | 🌗 | 🌕 | 🌑 | 经验复用：依靠过往案例经验来构建复杂的机器学习和深度学习流水线。 |
| **【二】核心代码生成与工具调用（Code Gen & Tooling）** | | | | | | |
| DS-1000                  | 🌑 | 🌗 | 🌗 | 🌗 | 🌑 | 基础 API：Pandas/NumPy (对应EDA) 和 Sklearn/PyTorch/TF (对应建模) 的片段级代码生成。 |
| LLM4DS                   | 🌑 | 🌗 | 🌗 | 🌗 | 🌑 | 代码评估：针对数据科学不同库（数据处理+模型库）的代码生成能力评估。 |
| ML-Bench                 | 🌑 | 🌗 | 🌑 | 🌕 | 🌑 | 真实开源库：基于 GitHub 真实机器学习项目，极度侧重 PyTorch/Sklearn 等建模代码实现与 Debug。 |
| **【三】数据准备与特征工程（Data Prep & Feature Eng）** | | | | | | |
| CAAFE                    | 🌑 | 🌕 | 🌑 | 🌑 | 🌑 | 上下文特征：结合业务上下文进行全自动特征工程，为后续建模提供弹药。 |
| Elf-gym                  | 🌑 | 🌕 | 🌑 | 🌑 | 🌑 | 特征评估：专门评估大模型为表格预测任务所生成特征的有效性。 |
| AutoDCWorkflow           | 🌑 | 🌕 | 🌑 | 🌑 | 🌑 | 数据清洗：评估大模型自动生成复杂数据清洗工作流的能力。 |
| TableBench               | 🌑 | 🌕 | 🌕 | 🌑 | 🌑 | 表格操作：针对复杂表格的切片、聚合、透视与异常值处理，纯数据级操作。 |
| **【四】领域数据推理与业务分析（Domain Reasoning）** | | | | | | |
| DataSciBench             | 🌗 | 🌕 | 🌕 | 🌗 | 🌕 | 真实业务：面对"脏数据"进行高强度的 EDA 与洞察分析，轻量级建模。 |
| DetoxBench               | 🌑 | 🌑 | 🌗 | 🌕 | 🌑 | 风控场景：针对欺诈和滥用检测，侧重分类预测与防作弊模型评估。 |
| FinQA / TAT-QA           | 🌗 | 🌑 | 🌕 | 🌑 | 🌑 | 高阶推理：结合文本与表格的财务数据提取，侧重业务上的算术逻辑推理。 |
| **【五】数据库交互与前端获取（Data Acquisition）** | | | | | | |
| BIRD-SQL / Spider        | 🌕 | 🌑 | 🌑 | 🌑 | 🌑 | 高难取数：将复杂业务问题转化为包含多表 Join 等高级操作的 SQL 语句。 |
| Business-RAG             | 🌕 | 🌑 | 🌗 | 🌑 | 🌑 | 信息提取：从业务文本/知识库中提取信息以供进一步商业洞察。 |
| **【六】数据可视化与呈现（Data Presentation）** | | | | | | |
| VisEval / ChartQA        | 🌑 | 🌑 | 🌑 | 🌑 | 🌕 | 图表呈现：根据自然语言生成图表，或从生成的图表中抽取结论。 |
