# Phase 1：提效助手 (Copilot)

## 核心目标

赋能专业人员，**单点提效**。不改变工作流程，只在关键环节降低摩擦。

## 落地场景示例

- 辅助编写复杂的 SQL 查询（多表 Join、窗口函数等）
- 快速生成图表可视化代码（省去查文档的时间）
- 清洗脏数据（自动识别异常值、填充缺失值的代码片段生成）

## 技术形态

类似 **DS-1000** 级别的代码生成与补全辅助工具。

核心能力要求：
- 准确的代码片段生成（Pandas / SQL / Sklearn）
- 上下文感知（理解当前数据 schema 和任务目标）
- 低误导率（错误代码比没有代码更危险）

## 阶段价值

门槛最低、见效最快。可以快速验证 LLM 在数据科学场景的实际可用性，同时积累真实 case 数据为 Phase 2/3 做准备。
