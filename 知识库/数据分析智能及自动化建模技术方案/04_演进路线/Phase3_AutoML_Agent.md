# Phase 3：自动化流水线 (AutoML Agent)

## 核心目标

**端到端的数据科学闭环**。给定原始业务数据和任务定义，系统自主完成从取数到输出预测结果的全流程。

## 落地场景示例

- 给定原始业务数据，自主完成特征清洗、模型选型并输出预测结果
- 新业务冷启动：基于历史相似任务经验，快速搭建第一版基线模型
- 持续学习：线上数据漂移时，自动触发重训练流程并完成评估对比

## 技术形态

类似 **MLE-bench** 级别的全栈多智能体协作框架。

核心能力要求：
- 多 Agent 协作（取数 Agent + 特征 Agent + 建模 Agent + 评估 Agent）
- 经验复用（参考 DS-Agent 的案例记忆机制）
- 全流程可观测（每步决策可追溯，避免黑盒）
- 业务指标对齐（离线 AUC → 在线 GMV 的转化路径要清晰）

## 阶段挑战

- **复杂度爆炸**：状态空间大，搜索效率 vs 质量的 tradeoff
- **错误传播**：上游特征工程的错误会被建模阶段放大
- **人机协作边界**：哪些决策需要人介入，哪些可以完全放手
