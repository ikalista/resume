# Phase 2：探索先锋 (EDA Agent)

## 核心目标

**降低数据分析门槛，释放人力**。让业务人员能自助完成初步数据探索，算法工程师从"翻译官"角色中解放。

## 落地场景示例

- 针对特定业务报表，自动进行归因分析（指标下降→维度下钻→原因定位）
- 输出结构化数据洞察报告（分布、异常、趋势、相关性）
- 交互式问数：业务人员用自然语言提问，Agent 自动取数 + 分析 + 回答

## 技术形态

类似 **DataSciBench** 场景，具备交互式数据查询能力的智能体。

核心能力要求：
- NL2SQL（取数智能化，参考 BIRD-SQL）
- 自动 EDA 报告生成（参考 InsightPilot）
- 归因分析能力（多维下钻、异常检测）
- 业务知识注入（避免统计正确但业务无意义的结论）

## 阶段挑战

- **冷启动**：新业务场景缺乏 schema 文档和业务口径定义
- **歧义消解**：同一指标名在不同业务线口径不同
- **可信度**：如何让业务人员信任 Agent 的分析结论
